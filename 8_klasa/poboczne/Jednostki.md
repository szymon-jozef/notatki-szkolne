# Ściąga
Jednostki typu małe:
decy \[d]- $0.1$
centry \[c] - $0.01$
mili \[m] - $0.001$
mikro \[$\micro$] - $0.000001$

Jednostki typu duże:
deko \[dag] - $10$
hekto \[h] - $100$
kilo \[k] - $1000$
mega \[M] - $1.000.000$

Jednostki czasu:
Minuta \[m] = $60$ sekund
Godzina \[h] = $60$ minut
Doba \[d] = $24$ godziny

Jednostki wagi:
Tona \[t] = $1000$ kg
