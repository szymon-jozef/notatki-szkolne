# System rzymski
| Znaczek | Znaczenie |
| ------- | --------- |
| I       | $1$       |
| V       | $5$       |
| X       | $10$<br>  |
| L       | $50$      |
| C       | $100$     |
| D       | $500$     |
| M       | $1000$    |
- Liczby, które są potęgami liczby $10$ mogą występować maksymalnie $3$ razy pod rząd.
- Jeśli mniejsza liczba jest przed większą to liczymy różnicę. Np. XL ($10$ $50$) = $40$, bo ($50 - 10 = 40$)
